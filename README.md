# Али Эркинов · Portfolio

Персональный сайт фотографа и дизайнера Али Эркинова.

## Сайт

https://dino-like.github.io/ali-erkinov-portfolio/

## Локальный запуск

Требуется Python 3. В папке проекта выполни:

```sh
python3 -m http.server 8080
```

Открой http://localhost:8080/ в браузере. Сборка и установка зависимостей не нужны.

## Структура

- `index.html`, `style.css`, `app.js`: интерфейс и интерактивные разделы.
- `art.json`: галерея вдохновения.
- `film.json`: фотографии в разделе The Film Roll.
- `shelf.json`: книги на полке.
- `assets/`: фотографии, видео, графика и шрифты.
